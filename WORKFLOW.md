# Workflow

DME_Lab advances by applying bounded pressure to unresolved questions,
preserving evidence, adjudicating only what the basis supports, and conserving
structure only when it prevents consequential collapse or repeated epistemic
work.

This file answers: **how does the Lab move?**

It defines current research/development governance. It is not a universal
scientific ontology.

## Core movement

A common movement is:

```text
pressure
→ observe / retrieve evidence
→ compare / transform / reconstruct
→ evaluate
→ adjudicate or dwell
→ preserve evidence + residue
→ update current standing / navigation where warranted
```

The order is not mandatory. Retained evidence may be reevaluated without fresh
observation. External change may supply new evidence without DME execution.

## Evidence before closure

Keep distinct:

- proposed;
- executed / implemented;
- directly observed;
- derived / reconstructed;
- interpreted;
- adjudicated;
- authorized;
- unresolved / missing.

Do not repair missing evidence with interpretation.

Direct evidence may contradict current projections, but evidence does not
silently adjudicate itself.

## Standing transition

```text
EVIDENCE
→ EVALUATION
→ ADJUDICATION
→ CURRENT STANDING
→ DERIVED PROJECTION
```

This is a governance relation, not a claim that every scientific specimen
contains each stage.

When new evidence conflicts with prior standing:

- retain the new evidence and its basis;
- retain the prior adjudication and its basis as lineage;
- do not rewrite historical evidence to make the present look coherent;
- adjudicate the current relation when warranted;
- update current-state/navigation projections only after standing changes.

```text
supersession != historical invalidation
compression != forgetting
```

## Pressure activation and reachability

Pressure maps are derived navigation.

```text
reachable
!=
active
!=
authorized for execution
```

A pressure becomes active only after explicit selection.

No next pressure activates automatically because it is reachable, elegant, or
exposed by a completed run.

Dwell is a legitimate result.

## Interpretation, authorization, execution

Current development authority is:

```text
interpretation / recommendation
!=
authorization
!=
execution
!=
semantic promotion
```

Reed is the current Executive authorization and synthesis point.

Council / reviewers may inspect evidence, reconstruct standing, challenge
claims, preserve disagreement, and propose pressures.

Council agreement does not authorize execution.

Workshop may execute only inside an explicitly authorized envelope and may not
promote its own output into standing.

If the execution boundary is ambiguous, stop or escalate rather than guessing.

## Pressure selection

Prefer:

```text
small intervention
→ large discrimination gain
→ sharper boundary
→ smaller next intervention
```

Normally maintain at most one active experimental pressure unless a separate
need independently justifies parallel work.

Research direction begins from consequential ambiguity, not from vocabulary
that happens to exist.

## Conservation and compression

Conserve a distinction, constraint, method, or root claim only when doing so:

- prevents demonstrated drift or unsupported collapse;
- preserves a consequential authority/evidence boundary;
- supports reconstruction;
- reduces repeated epistemically meaningful work.

Otherwise leave the system lighter.

Compression success criterion:

```text
smaller live governing surface
+
same recoverable consequential distinctions
+
same or clearer authority routing
```

Compression fails if it hides contradiction, loses basis/provenance, erases
historical standing, or increases reconstruction debt enough that correct
action becomes harder.

## Navigation update

After adjudication:

- record the bounded resolution;
- preserve residue;
- link authoritative evidence;
- update current-state and navigation projections that are now stale;
- expose changed reachability;
- do not automatically authorize new execution.

reachability.

[DEVELOPMENT_PRESSURE_MAP.md](DEVELOPMENT_PRESSURE_MAP.md) navigates
development reachability.

Neither map is evidence for itself.

## Local and compositional pressure

Every active research pressure is evaluated on two independent dimensions:

LOCAL SUFFICIENCY
What is the smallest mechanism that resolves or sharpens the present pressure?

COMPOSITIONAL COMPATIBILITY
If preserved, can that mechanism coexist with already-earned structure without
unsupported collapse, contradiction, or silent strengthening?

global compatibility != local necessity
local sufficiency != global architecture

Possible bounded outcomes include:

LOCAL-ONLY SURVIVOR
COMPOSITIONALLY COMPATIBLE
LOCALLY + COMPOSITIONALLY EARNED
OVERBUILT
INCOMPATIBLE
BASIS INSUFFICIENT

If either dimension is unresolved, preserve that unresolvedness rather than
promoting the mechanism.
