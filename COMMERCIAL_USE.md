## Commercial use

Commercial use of DME_Lab, ATLAS implementation code, or modified/new works
based on covered repository software requires separate permission from the
repository owner.

Examples that should be treated as requiring a separate commercial license
include:

- selling or relicensing the covered software;
- offering a paid hosted or managed service based on the covered software;
- incorporating covered software into a commercial product or paid customer
  deliverable;
- repackaging or redistributing covered software for commercial advantage; and
- other uses whose purpose or anticipated application is commercial and is not
  otherwise permitted by the controlling license.

When in doubt, request a commercial license before using covered software for a
commercial purpose.

Commercial licensing may be negotiated separately with the repository owner.
No commercial rights arise merely because the source code is publicly visible.
