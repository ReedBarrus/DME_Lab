# DME Development Campaign v0

**Status:** PROVISIONAL CAMPAIGN  
**Standing:** Directional development map, explicitly attackable and revisable  
**Purpose:** Replace probe-by-probe drift with a bounded campaign that advances the highest-leverage coupled frontiers while preserving evidence discipline.

---

## 0. Campaign Objective

Build a system in which independently situated agents can:

```text
enter from a bounded continuity coordinate
→ consume only relevant deltas
→ reconstruct qualified working state
→ perform useful internal work
→ leave durable, attributable consequence
→ surface unresolved pressure
→ request human/external authorization only when required
```

without collapsing:

```text
epistemic state
capability state
authority state
execution state
```

into one another.

The campaign succeeds only if the resulting machinery produces measurable operational rent.

---

# 1. Campaign Regime

Default development regime:

```text
high epistemic permeability
high feedback frequency
bounded semantic debt
bounded coupling
low authority permeability
high reversibility
consequence-sensitive compression
developmental bias toward informative feedback
```

External consequence remains conservative.

Governing operational principle:

```text
act when admissible
probe when debt matters
hold when neither is warranted
learn from consequence
```

# 2. Four Coupled Frontiers

## FRONTIER A — Semantic Continuity

Goal:

```text
reliable meaning-bearing passage across agent/context boundaries
```

Current earned substrate:

```text
explicit bootstrap navigation
FROM_ORIGIN / FROM_HEAD / AFTER_EVENT
contiguous ACK_ONE
no backward acknowledgement
no skipped unread events
semantic application != standing promotion
missing/conflicting basis blocks application
later exact basis can reopen applicability
acknowledgement != semantic standing promotion
cursor continuity != semantic-state continuity
bounded materialization can restore fresh-context recovery
```

Current unresolved:

```text
materialization failure atomicity
project-wide current-state representation
automatic capture
real ChatGPT↔Codex continuity passage
consumer/thread/model association
continuity manager projection
measured continuity rent
```

Campaign target:

> A real agent can leave, return in a fresh context, consume only relevant retained state, recover bounded semantic continuity, perform useful work, and leave new durable consequence without human reconstruction middleware.

---

## FRONTIER B — Capability Expansion

Goal:

```text
make missing degrees of freedom visible and requestable
without silently widening authority
```

Core distinction:

```text
AVAILABLE
!=
QUALIFIED
!=
AUTHORIZED
!=
ADMITTED
```

A capability may be:

```text
discoverable
useful for current pressure
not authorized
therefore not executable
```

Candidate capability record:

```text
CAPABILITY_ID
DOMAIN
AVAILABLE
QUALIFIED_FOR
REQUIRED_AUTHORITY
CURRENT_AUTHORITY
CONSEQUENCE_CLASS
REVERSIBILITY
EVIDENCE_REFS
```

This representation is not yet earned runtime structure.

Campaign target:

> Agents can identify when a tool/domain would materially reduce unresolved pressure and surface that capability request without granting themselves the right to use it.

---

## FRONTIER C — Authority & Security

Goal:

```text
prevent competence, usefulness, momentum, or capability from becoming self-authorization
```

Hard non-collapse chain:

```text
PROPOSE
!=
AUTHORIZE
!=
EXECUTE
!=
VERIFY CONSEQUENCE
```

Additional guard:

```text
capability expansion
!-> authority expansion
```

For any action with material external, financial, legal, security, public, or difficult-to-reverse consequence:

```text
CONFIRM AUTHORIZATION EXPLICITLY
```

is the required human authorization key unless and until a narrower delegated authority contract is explicitly established.

Campaign target:

> Internal work can proceed with high autonomy while external consequence remains bounded by explicit authority, typed scope, reversibility, and auditability.

## FRONTIER D — Consequence, Cost & Economic Feedback

Goal:

```text
measure whether semantic machinery pays operational and economic rent
```

Internal costs:

```text

semantic debt

error correction
```

External consequences:

```text
time saved
```

Candidate criterion:

```text
probe / structure / capability cost

```

Campaign target:

# 4. Campaign Navigation

The next action is not chosen merely because it is the smallest local pressure.

A proposed pressure should be evaluated against:

```text
Which frontier does it advance?
What dependency does it unblock?
What risk/debt does it expose?
What measurable consequence could change?
Is another frontier currently more constraining?
```

Default priority:

```text
1. repair false continuity / false authority
2. establish minimal operational passage
3. expose blocked capability
4. establish safe authority boundary
5. measure consequence-cost rent
6. widen only after local rent is observed
```

# 5. Immediate Campaign Sequence

## Phase 1 — Finish Continuity v0

Required before widening:

```text
materialization failure atomicity
one real project-level current-state specimen
one real ChatGPT↔Codex passage
structured note/event production
fresh-context recovery
measured reads/context/human corrections
```

Exit criterion:

> Real agents can exchange bounded semantic continuity with equal or better standing fidelity and lower human reconstruction burden than the previous document-reconstruction baseline.

## Phase 2 — Visibility / Cockpit Projection

Build only projections over earned state.

Minimum useful cockpit:

```text
CURRENT REGIME
CURRENT CAMPAIGN FRONT
EXECUTABLE FRONTIER
LATEST EARNED CHECKPOINT
ACTIVE PRESSURES
QUEUED PRESSURES
BLOCKED ON HUMAN
BLOCKED ON AGENT
AUTHORIZATION STATE
EXTERNAL CONSEQUENCE EXPOSURE
SEMANTIC / TECHNICAL DEBT
LATEST COST / PAYOFF SIGNAL
```

The cockpit is derived operational visibility, not authority.

## Phase 3 — Capability Requests

Pressure agents to identify missing tools/domains without exercising them.

Test:

```text
pressure
→ missing capability identified
→ qualification stated
→ authority remains unchanged
→ explicit request surfaced
```

Exit criterion:

> Capability discovery becomes legible without producing self-authorization.

## Phase 4 — Authority Membrane

Formalize and pressure:

```text
propose
authorize
execute
verify
```

as separate transitions.

Test dangerous collapse cases:

```text
useful -> authorized
available -> admitted
previous authorization -> current authorization
agent-written authority -> agent-exercised authority
execution success -> standing promotion
```

Exit criterion:

> No tested internal transition can silently widen external authority.

## Phase 5 — Cost / Compression Workshop

Compare regimes and representations against:

```text
context cost
reconstruction cost
semantic error
coupling density
task latency
human correction burden
external payoff
```

Questions:

```text
When is materialization cheaper than reconstruction?
When does semantic compression preserve enough consequence?
When does additional dimensionality improve navigation?
When does coupling become burden rather than leverage?
```

## Phase 6 — Bounded External Entry

Only after authority/security audit.

Start with:

```text
low consequence
low spend
high reversibility
high observability
explicit authorization
```

No autonomous economic scaling before local consequence-control evidence exists.

# 6. Campaign Attack

## Attack A — Continuity Becomes a Rumor Machine

Failure:

```text
activity recorded
→ treated as verified result
→ treated as standing change
```

Guard:

```text
ACTIVITY_RECORDED
!=
RESULT_VERIFIED
!=
STANDING_CHANGED
```

## Attack B — Materialized State Fossilizes the System

Failure:

```text
current projection
→ mistaken for authoritative ontology
```

Guard:

```text
materialized current state
=
bounded working projection with provenance and standing
```

not world truth.

## Attack C — Capability Becomes Authority

Failure:

```text
tool available
→ tool useful
→ tool executed
```

Guard:

```text
AVAILABLE != QUALIFIED != AUTHORIZED != ADMITTED
```

## Attack D — Human Authorization Becomes Ritual Noise

Failure:

```text
CONFIRM AUTHORIZATION EXPLICITLY
```

is requested so often that it becomes automatic rubber-stamping.

Guard:

Authorization requests must expose:

```text
requested action
scope
consequence class
cost/spend
reversibility
affected systems
why authorization is required
```

## Attack E — Agent Self-Authorization

Catastrophic failure:

```text
agent modifies authority state
+
agent executes under modified authority
```

This path is invalid by default unless an external authority contract explicitly delegates both actions under bounded conditions.

## Attack F — False Safety by Internal Elegance

Failure:

```text
clean semantics
→ assumed safe external action
```

Guard:

```text
semantic coherence
!=
external correctness
!=
external authorization
```

## Attack G — Infinite Probe Loop

Failure:

```text
every result produces another smallest pressure
→ local rigor
→ no integrated capability
```

Guard:

Campaign map outranks local curiosity when local pressure no longer advances the constraining frontier.

## Attack H — Cockpit Becomes Another Authority File

Failure:

```text
derived projection
→ treated as source of truth
```

Guard:

Cockpit must expose refs and ownership; it does not own facts merely by displaying them.

## Attack I — Debt Accounting Becomes Fake Precision

Failure:

```text
semantic debt score
→ arbitrary number
→ false confidence
```

Guard:

Debt remains typed/qualified until measurement earns numeric models.

## Attack J — Economic Incentive Corrupts Epistemics

Failure:

```text
revenue signal
→ pressure to promote weak claims or unsafe execution
```

Guard:

Economic payoff cannot itself promote epistemic standing or authority.
