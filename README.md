# DME_Lab

## What DME_Lab is

DME_Lab is an evidence-driven laboratory for learning how bounded evidence can
remain reconstructible across changes in source, representation,
interpretation, and intervention without collapsing distinctions the evidence
still supports.

This objective is the current primary basis. It was migrated live after bounded
constitutional pressure, two independent semantic round-trip reconstructions
over the same immutable candidate basis, and explicit Executive authorization.

The Lab began with deterministic reconstruction of OS-derived event history
with provenance intact. That remains a founding observation regime and active
lineage, not a requirement that every later evidence regime resemble OS events.

## Governing discipline

Current pressure supports these boundaries:

```text
EVIDENCE != INTERPRETATION
INTERPRETATION != AUTHORIZATION
AUTHORIZATION != EXECUTION

REPRESENTATION / PROJECTION != SOURCE EVIDENCE
DECLARED BASIS != UNIVERSAL VALIDITY
MISSING / UNRESOLVED != KNOWN
```

Distinct source regimes are not equivalent merely because they concern the same
apparent world.

The strongest current conservation rule is:

> No downstream surface may silently strengthen upstream warrant.

These are bounded repository disciplines, not a complete ontology.

## Evidence and lineage

Scientific and implementation claims remain grounded in committed source,
runtime behavior, tests, traces, retained artifacts, and adjudicated decision
records under declared bases.

Derived projections, pressure maps, contracts, constraints, and participant
summaries have narrower roles. Their currentness does not let them override
contradictory direct evidence.

Historical decisions and superseded wording remain recoverable as lineage.
Supersession is not deletion or retroactive invalidation.

DME_Theory remains lineage, not authority.
