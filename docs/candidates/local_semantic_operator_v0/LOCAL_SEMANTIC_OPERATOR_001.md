## Pressure cells

```text
S1 VALID TYPED PROPOSAL
   valid request
   temporary lease acquired
   provider returns exact typed proposal
   → proposal retained
   → lease released
   → seat state unchanged

S2 MALFORMED MODEL RESPONSE
   provider returns non-JSON / malformed content
   → raw provider evidence retained
   → proposal invalid
   → no seat transition

S3 EXTRA UNSUPPORTED FIELD
   model returns valid JSON plus undeclared field
   → schema INVALID
   → no seat transition

S4 UNAUTHORIZED ACTION SUGGESTION
   model suggests REQUEST_REVIEW / REVALIDATE
   → suggestion may be retained
   → action_selection_effect = NONE
   → nothing executed

S5 PROVIDER FAILURE
   timeout / connection / server failure
   → failure receipt retained
   → lease released
   → no proposal treated as valid

S6 FALSE EVIDENCE REFERENCE
   model cites evidence not in request basis
   → proposal INVALID
   → no silent evidence expansion

S7 DUPLICATE REQUEST
   same request identity and bytes replayed
   → retained outcome returned
   → no second model invocation

S8 BASIS MOVES DURING COGNITION
   request begins at seat/environment basis B1
   basis changes before proposal return
   → proposal may exist
   → current_basis_status = STALE
   → no state mutation
```


## Claim ceiling

A passing candidate may support only that the tested controller-mediated
semantic path can issue a bounded proposal-only request through a temporary
model lease, validate typed output and evidence references, detect basis drift,
retain provider failures, and avoid seat/action/authority effects under the
tested cells.

It does not establish:

