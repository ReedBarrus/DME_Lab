# Concordance Cockpit v0 — primitive projection candidate

Status:

```text
DEVELOPMENT CANDIDATE
NOT A SCIENTIFIC CLAIM
NOT A GOVERNANCE ROOT
NOT AN AUTHORITY SOURCE
NOT MERGED
```

This candidate materializes a thin cockpit structure for rendering a persistent
ecology without turning the UI into an authority, standing, or causality oracle.

Core non-collapses:

```text

!=

!=

```

The v0 projector renders five core object classes:

```text
SEAT_v0
OPERATION_v0
ARTIFACT_REF_v0
HANDOFF_v0
FRACTURE_v0
```

and one optional evidence-bearing developmental relation object:

```text
DEVELOPMENT_EDGE_v0
```

A supported developmental edge requires:

```text
from_ref
to_ref
relation_type
non-empty basis_refs
all basis refs present
status = SUPPORTED
```

Otherwise it is exposed under:

```text
unresolved_relations
```

rather than promoted into the supported graph.

Authority handling is deliberately weaker than a full resolver:

```text
authority_ref
=
reference exposed by the operation

authority_state
=
UNRESOLVED_BY_V0
```

The projector may report whether the referenced artifact is present. It does not
interpret that artifact into executable authority.

This is intentional:

```text
DISPLAYED AUTHORITY REFERENCE
!=
AUTHORITY SOURCE
```

The first candidate is therefore a conservative data/projection primitive, not
yet a graphical cockpit implementation.

If retained, the next development pressure can ask whether the existing Cockpit
observer can render this projection without visually implying unsupported
authority, standing, or developmental causality.
