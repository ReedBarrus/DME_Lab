## Governing question

> What have we actually earned the right to conclude?

## Compact method

Given an apparent implication:

```text
X → Y
```

apply:

```text
CLAIM
→ identify the implied consequence

EXPOSE
→ identify candidate mediating relations

PRESSURE
→ vary candidate relations independently

KEEP
→ retain only distinctions whose variation
  changes an observable consequence

BIND
→ allow evidence to update only the relation
  it actually supports

RECOMPOSE
→ rebuild the mechanism from surviving relations

PRESSURE AGAIN
→ test the recomposed implication
```

## Anti-inflation test

A candidate distinction is not earned merely because it can be named.

Ask:

```text
Can A vary while B remains fixed?
Can B vary while A remains fixed?
Does the difference change an observable consequence?
```

If independent variation cannot be produced, retain the distinction only as a
candidate.

If independent variation is possible but nothing consequential changes, the
distinction may be vocabulary rather than mechanism.

If independent variation changes a bounded observable consequence, the
distinction has pressure-earned standing in that tested scope.

## Recomposition requirement

```text
DECOMPOSE
!=
FINISH
```

The method requires recomposition and renewed pressure. Otherwise decomposition
can grow vocabulary without improving discrimination.

applicability.

That history motivates continued use.

It does not establish that the method is complete, optimal, or domain-general.
