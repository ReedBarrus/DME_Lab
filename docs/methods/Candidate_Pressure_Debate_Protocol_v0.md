# Candidate Pressure Debate Protocol v0

**Status:** research-method projection  
**Purpose:** compare competing global candidate compositions without allowing elegance, authorship, or agent preference to outrank repository evidence.

## 1. Authority and standing

The debate operates under this authority order:

1. authoritative repository evidence and current repo state;
2. the bounded Observatory projection of that evidence;
3. candidate projection documents;
4. agent arguments.

Candidate compositions are **not architecture**, **not implementation requirements**, and **not scientific standing**.

Every debate includes a **Null Candidate**:

> No shared abstraction beyond the smallest mechanism required by the current pressure is yet justified.

This prevents a forced choice between generated architectures.

---

## 2. Coupled audit

Every candidate mechanism is evaluated on two independent dimensions.

### LOCAL SUFFICIENCY

Does the mechanism actually discriminate, resolve, or sharpen the present pressure?

### COMPOSITIONAL COMPATIBILITY

If preserved, can the mechanism compose with already-earned structures without erasing distinctions, introducing contradiction, or silently strengthening semantics?

Guardrails:

> global compatibility does not imply local necessity

> local sufficiency does not imply global architecture

---

## 3. Atomic collision

Do not debate whole architectures at once.

Each debate isolates one **atomic collision**:

- Candidate A claim
- Candidate B claim
- Null claim
- shared ground
- one consequential difference
- one local pressure
- one global/compositional pressure
- distinct predictions
- smallest executable discriminator
- stop condition

If the candidates make no distinct prediction under the current basis, the result is not a winner. Record equivalence, ambiguity, or insufficient basis.

---

## 4. Rotating roles

For each atomic collision, run three candidate-centered rounds.

### Round A

- ChatGPT — Advocate Candidate A
- Astra — Adversary
- Codex — Experimentalist

### Round B

- Astra — Advocate Candidate B
- Codex — Adversary
- ChatGPT — Experimentalist

### Round Null

- Codex — Advocate Null
- ChatGPT — Adversary
- Astra — Experimentalist

Roles rotate so no model permanently defends the composition it helped author.

### Advocate

State the strongest precise version of the assigned candidate claim.

Must:
- preserve the candidate's actual commitments;
- name assumptions;
- state what the candidate predicts under the pressure;
- state what would count against it;
- avoid adding rescue machinery.

### Adversary

Attack the active claim and the collision framing.

Look for:
- hidden assumptions;
- unnecessary primitives;
- semantic collapse;
- circular warrant;
- unearned composition;
- counterexamples;
- cases where the Null Candidate is enough;
- cases where a rival candidate predicts the same observation.

The adversary must identify whether the disagreement is executable or merely terminological.

### Experimentalist

Ignore elegance and architecture.

Produce the smallest executable pressure that could discriminate the live claims.

Must specify:
- source/specimen;
- bounded observation basis;
- intervention;
- captured coordinates;
- competing predictions;
- failure criterion;
- residue;
- stop condition.

If no executable discriminator exists yet, say `BASIS INSUFFICIENT` and name the missing coordinate.

---

## 5. Round isolation and synthesis

Each candidate-centered round should initially preserve its own reasoning boundary.

After all three rounds, run a synthesis pass over the recorded outputs.

The synthesis does not crown a global winner. It adjudicates individual claims or components.

Possible workflow outcomes:

- `LOCAL-ONLY SURVIVOR`
- `COMPOSITIONALLY COMPATIBLE`
- `LOCALLY + COMPOSITIONALLY EARNED`
- `OVERBUILT`
- `INCOMPATIBLE`
- `BASIS INSUFFICIENT`

Additional useful debate outcomes:

- `EQUIVALENT UNDER CURRENT PRESSURE`
- `DISTINCT PREDICTIONS — EXECUTION WARRANTED`
- `TERMINOLOGICAL DIFFERENCE ONLY`

These debate outcomes do not automatically become Pressure / Resolution Map standings.

---

## 6. Reality gate

A candidate claim is not promoted because agents agree.

The movement is:

```text
candidate claims
→ atomic collision
→ rotating debate
→ distinct predictions?
    no → preserve equivalence / ambiguity
    yes
→ smallest executable pressure
→ Reed authorizes one pressure
→ bounded execution
→ evidence
→ repo adjudication
→ candidate revision
```

Reed selects or authorizes the pressure.

Codex or another bounded investigator may execute it.

Repository evidence adjudicates what survives.

# First Collision — PR-006 / Hidden Traversal

## Current repo pressure

PR-006 asks whether a narrowly selected source-relative change coordinate could discriminate hidden intervals, externally stale history, or sequential source skew under a concrete consumer basis.

For the first debate, narrow PR-006 to one inherited ambiguity from PR-001:

> Given equivalent captured endpoint states, can a bounded source-relative observation distinguish true stasis from an unobserved `A → B → A` traversal?

Do **not** solve stale reconstruction or cross-source skew in this first collision.

## Concrete consumer question

> Did the selected repository source undergo at least one relevant source-relative change between endpoint captures?

This is intentionally narrower than:

- what complete transformation history occurred;
- why the change occurred;
- whether another source changed simultaneously;
- what semantic consequence the change had.

## Candidate A claim

A strong local reading of Consequential Geometry A is:

> Endpoint state and traversal evidence are distinct coordinates. A legitimate discriminator must be situated under a declared observation basis and preserve enough provenance to warrant the traversal claim. A source-relative traversal witness may be sufficient locally without requiring the full global consequence tuple, but the witness must not be collapsed into endpoint state or treated as complete transformation history.

Candidate A therefore predicts that a bounded witness can distinguish stasis from hidden traversal **only relative to its declared source, scope, and provenance boundary**.

## Candidate B claim

A strong local reading of Consequence Formal B is:

> No global chart/configuration machinery is required for this pressure. Define a semantic scope and a bounded observer relation. The observation result induces a compatibility set over possible source histories. A useful additional witness is one that separates the stasis and hidden-traversal possibilities. Evidence terms record the assumptions and association supporting that result.

Candidate B therefore predicts that the pressure can be stated and adjudicated through scoped possibility discrimination without instantiating a richer consequential-geometry object.

## Null claim

> A simple source-relative persistent change witness is enough for the binary consumer question. For example, a monotonic source version, change counter, append-only source event, or equivalent irreversible activity coordinate could separate stasis from `A → B → A`. No generalized observer geometry is currently required.

The Null Candidate does not deny that richer structure may later become useful. It denies that PR-006 currently requires it.

## Shared ground

All three candidates should preserve:

```text
endpoint equality
!=
complete transformation history
```

and:

```text
endpoint state
!=
traversal evidence
```

A useful witness must not silently establish:

- exact hidden path;
- cause;
- semantic consequence;
- cross-source simultaneity;
- complete history.

## Actual consequential difference

The first debate should determine whether the smallest legitimate discriminator is merely:

```text
persistent source-relative change witness
```

or whether local legitimacy already requires an explicit formal observation structure such as:

```text
source/scope/basis
+ witness semantics
+ provenance/association boundary
```

and whether Candidate A and Candidate B make any experimentally different demand beyond notation.

## Local sufficiency question

What is the minimum retained coordinate required to answer:

> did at least one selected source-relative change occur during the otherwise unobserved interval?

## Global / compositional question

If the winning local witness is later composed with:

- stale-history detection;
- cross-source timing;
- reconstruction;
- provenance;
- recoverability;

what distinctions must already have been retained to avoid an irreversible semantic collapse?

This question may reveal future compatibility requirements, but it must not force them into the first implementation unless the local pressure needs them.

## Initial stop rule

If A and B accept the same smallest witness and differ only in how they formalize its meaning, classify them:

`EQUIVALENT UNDER CURRENT PRESSURE`

and pressure Null versus the shared A/B requirement.

If A or B requires an additional coordinate whose absence produces a different executable result, preserve that as the next discriminator.

If no candidate yields an executable difference, do not implement a geometry. Record the unresolved abstraction boundary.
