## Human basis

The next goal is not to collect more obvious rules.

The goal is to turn earned relations into a reusable cycle:

```text
OBSERVE
→ IDENTIFY RELATION
→ IDENTIFY SURFACE CONFIGURATION
→ APPLY / WITNESS TRANSFORMATION
→ TEST FLOW / CONSEQUENCE
→ QUALIFY WHAT SURVIVES
→ CATALOGUE INVARIANT
→ COMPRESS OPERATIVE CARRIER
→ RETAIN RICH EVIDENCE COLD
→ MEASURE RECONSTRUCTION + COST
→ REVALIDATE WHEN CURRENTNESS CHANGES
```

Known relational law should not be re-proven merely because it appears on a new
surface.

Instead:

```text
KNOWN RELATIONAL LAW
+
NEW SURFACE GEOMETRY
→ INSTANTIATE
→ PRESSURE ONLY THE UNKNOWN PART
```

The unknown part may be:
- how the relation is represented on that surface;
- what transformation is admissible;
- what observation is valid;
- what propagates;
- what must remain invariant;
- what counts as rupture or recovery.
