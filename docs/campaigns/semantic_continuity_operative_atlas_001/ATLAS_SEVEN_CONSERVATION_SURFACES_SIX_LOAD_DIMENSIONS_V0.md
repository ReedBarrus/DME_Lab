The current V0 load vector is six-dimensional.

LOAD(object / relation):

1. FUNCTIONAL LOAD

2. SEMANTIC LOAD

4. PROVENANCE LOAD

5. TEMPORAL LOAD

What continuity, lineage, or recoverable state transition breaks?

6. COORDINATION LOAD

Which seats, workflows, or handoffs lose orientation or operational
continuity?

# ==================================================
# 6. SIX-DIMENSIONAL LOAD LAW
# ==================================================

Represent provisionally:

L(x)
=
{
  functional,
  semantic,
  authority,
  provenance,
  temporal,
  coordination

A relation may carry high load in one dimension and low load in another.

a distinction may carry:

high semantic load
high provenance load
low direct functional load

while an executor module may carry:

high functional load
high authority load
low symbolic authorship load

PRESSURE TARGET:

- seat loss;
- provenance loss;
- temporal replay;
- reconstruction;
- authority revocation?
