# Atlas Artifacts

This folder contains Atlas-named continuity, metabolism, planning, workflow, and load-transfer artifacts.

High-density families are batched topologically:

- `bridge/`
- `coordination_rounds/`
- `horizon_reviews/`
- `load_transfer/`
- `metabolism/`
- `planner/`
- `temporal_wounds/`

Lower-density Atlas artifacts remain at this folder root until a coherent family crosses the topology-review threshold.

Location is navigational only. Folder membership does not create scientific standing, authority, or execution effect.
