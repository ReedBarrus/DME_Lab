# Atlas Temporal / Actor / Wound Instrument Quality Ledger V0

Basis: `ATLAS_TEMPORAL_LINEAGE_ACTOR_WOUND_REPLAY_V0`

Standing: implementation-pressure observation only. This ledger does not
promote scientific standing, authority, actor attribution, or semantic cause.

## MORE VISIBLE

- The repository can be traversed through 386 exact first-parent frames.
- Adjacent source changes appear as challengeable transition emissions.
- LABBOIB is visually distinct from passive repository files once its seat
  manifest exists; its cursor is a separately addressed object.
- Git authorship, seat evidence, and unresolved semantic causation appear as
  separate fields rather than one provenance label.

## EASIER TO REASON ABOUT

- Same-path persistence can be compared directly with changing blob/content
  identities.
- A cursor transition can be distinguished from seat activity, authority, or
  attention.
- Every wound step retains exact from/to frames, event identity, blob pair,
  and Git diff handles.

## HARDER / NOISIER

- A frame containing roughly two thousand objects can still produce many
  local emissions after a large commit.
- First-parent history is a declared linearization and does not expose every
  second-parent branch frame on the slider.
- Temporal controls, Cell-002 controls, and structural controls compete for
  vertical dock space; independent scrolling keeps the field usable but does
  not remove that density.

## MISLEADING MOTION

- Early rendering made every transition ring equally prominent. V0 now uses
  local, regional, and global scale regimes over the same retained event IDs.
- Emissions remain static bounded cues rather than fabricated continuous
  motion. No emission is labeled as semantic cause.

## MISSING LINEAGE

- Most historical mutations have no explicit seat actor binding.
- Commit author and committer metadata cannot repair the missing seat actor.
- The selected wound has no exact source-to-result relation establishing why
  each code mutation occurred.

## MISSING RELATION

  sources do not explicitly provide them.
- No source establishes seat attention, seat causation of a commit, or complete
  semantic intent for the wound.
- The first-parent slider does not represent the full merge DAG.
