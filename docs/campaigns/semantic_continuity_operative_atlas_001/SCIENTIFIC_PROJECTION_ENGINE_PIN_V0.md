# ==================================================
# DETERMINISTIC-SEMANTIC GATES
# ==================================================

CANONICAL WORKING TERM:

ELIGIBILITY GATE

An eligibility gate is a deterministic / typed relation over
projected current state that determines whether a candidate action
is eligible to proceed to authority evaluation.

Example form:

IF

basis_currentness = CURRENT
AND
translation_standing = QUALIFIED_FOR_SCOPE
AND
required_observation_depth = SATISFIED
AND
authority_coordinates = CORRESPONDING
AND
candidate_consequence_surface within declared bounds

THEN

ACTION_ELIGIBILITY = ELIGIBLE_FOR_AUTHORITY_REVIEW

ELSE

ACTION_ELIGIBILITY = INELIGIBLE / REVALIDATION_REQUIRED / UNRESOLVED

FREEZE:

ELIGIBILITY GATE
!=
AUTHORITY GRANT

ELIGIBILITY GATE
!=
EXECUTION

Eligibility gates may become one component of watcher-like regulation
when placed at consequential boundaries such as:

tool invocation
network access
filesystem mutation
process creation
authority derivation
model invocation
promotion / merge
canonical-state mutation

They reduce reliance on unconstrained semantic judgment by requiring
explicit relational conditions before authority may even be considered.
