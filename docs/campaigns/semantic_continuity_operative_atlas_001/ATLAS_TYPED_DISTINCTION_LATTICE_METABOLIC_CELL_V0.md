# 4. DETERMINISTIC DIFFERENTIATION TARGET
# ==================================================

A major research target is to determine how cleanly the system can
differentiate symbolic geometry from relational geometry.

Current provisional distinction:

SYMBOLIC GEOMETRY asks:

WHAT DISTINCTION / TYPE / CLAIM / MEANING
IS REPRESENTED?

RELATIONAL GEOMETRY asks:

WHAT STRUCTURAL RELATION
HOLDS BETWEEN REFERENTS?

One typed distinction cell may contribute to both.

Example:

SYMBOLIC:
PATH_IDENTITY != CONTENT_IDENTITY

RELATIONAL:
file_at_path
HAS_VERSION
blob_identity

The symbolic distinction interprets a mechanically supported relation.

The relational structure anchors where the distinction applies.

Do not collapse these until pressure demonstrates they are redundant.

# ==================================================
# 13. FIRST RECONSTRUCTION PRESSURE
# ==================================================

For each distinction cell:

1. construct from admitted source;

2. register into Atlas;

3. remove original conversation / prose context;

4. provide a fresh seat only:
   - Atlas address;
   - local frame;
   - registered distinction cell;
   - source handles;

5. ask the seat to reconstruct:
   - the distinction;
   - what supports it;
   - where it applies;
   - claim ceiling;
   - dependencies;
   - unresolveds;

6. compare reconstruction to the admitted source.

Success is not identical prose.

Success is conserved operational posture.
