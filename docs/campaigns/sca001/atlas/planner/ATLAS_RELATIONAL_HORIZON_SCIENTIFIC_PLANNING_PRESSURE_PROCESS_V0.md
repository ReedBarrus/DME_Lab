# ==================================================
# RELATIONAL-PROCEDURAL HORIZON
# ==================================================

A RELATIONAL-PROCEDURAL HORIZON is a bounded future capability,
relation, failure surface, transition law, or governance boundary whose
attainment would require coordinated progress across one or more primary
axes.

A horizon should state:

- TARGET_RELATION_OR_CAPABILITY
- CURRENT_FRAME
- AXES_INVOLVED
- REQUIRED_CONSERVATIONS
- KNOWN_BLOCKERS
- PROJECTED_CONSEQUENTIAL_FRAMES
- PRESSURE_FAMILY
- SUCCESS_WITNESSES
- CLAIM_CEILING

# ==================================================
# EXPERIMENTAL PLANNING PROCEDURE
# ==================================================

1. OBSERVE CURRENT QUALIFIED FRAME

Recover current standing without importing stale conversation context.

2. MAP PRIMARY-AXIS EXPOSURE

For each relevant axis, ask:
- what is currently represented?
- what is conserved?
- what is missing?
- what failure would become consequential?

3. PROJECT CONSEQUENTIAL FRAMES

Construct at least two bounded future frames:
- one reachable if the relevant conservation holds;
- one reachable if it fails or remains unresolved.

4. IDENTIFY HORIZON

Select the relation/capability boundary that distinguishes those
consequential frames and is decision-relevant to the target.

5. DECOMPOSE INTO PRESSURE FAMILY

Convert the horizon into an ordered family of falsifiable local pressures.

6. RUN LOCAL SCIENTIFIC LOOPS

Use the bounded execution loop for each pressure.

7. REASSESS HORIZON

After qualification, compare the new current frame against the horizon.
Continue, repair, branch, compress, or replan.
