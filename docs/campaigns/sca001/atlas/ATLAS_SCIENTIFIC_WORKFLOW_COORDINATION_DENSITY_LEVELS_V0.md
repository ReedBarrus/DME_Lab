# PURPOSE

Define four coordination-density levels that preserve scientific
continuity while allowing multiple bounded experimental objects to move
through the workflow efficiently.

These levels are candidate-canonical for the current scientific workflow.
Additional levels may be appended later without rewriting the distinctions
established here.

# CORE NON-COLLAPSE

SCIENTIFIC_ATOMICITY
!=
COORDINATION_ATOMICITY
!=
PLANNING_ATOMICITY

A scientific unit may need to remain isolated even when multiple units are
coordinated in one human round.

# LEVEL 1 — ISOLATED PRESSURE

USE WHEN:
- blindness matters;
- source independence matters;
- prior-context exclusion matters;
- a fresh extraction/reconstruction is the experiment.

FORM:
ONE SPECIMEN
+
ONE FRESH INSTANCE
+
ONE BOUNDED TASK
+
ONE FROZEN OUTPUT

REQUIREMENTS:
- no access to sibling variants unless explicitly part of the contract;
- no evaluator material before output freeze;
- no self-adjudication;
- no imported workflow context beyond the packet;
- result frozen before any later comparison or pressure exposure.

CANONICAL HUMAN ACTION:
SEND THIS → TO FRESH INSTANCE → RUN ONLY THIS → RETURN EXACT OUTPUT

# LEVEL 2 — COMPARATIVE PRESSURE

USE WHEN:
- comparison itself is the experiment;
- multiple already-frozen objects must be evaluated together;
- matched variants or cross-instance results are intentionally contrasted.

FORM:
TWO OR MORE FROZEN OBJECTS
+
EXPLICIT MATCHING / CONTRAST CONTRACT
+
ONE COMPARATIVE EVALUATOR
+
ONE FROZEN COMPARISON RESULT

REQUIREMENTS:
- each constituent object must already be frozen where independence matters;
- comparison dimensions must be declared;
- the evaluator must not repair or regenerate constituent objects;
- the comparison may not retroactively contaminate the original runs.

CANONICAL HUMAN ACTION:
SEND FROZEN SET → TO COMPARATIVE EVALUATOR → APPLY MATCH CONTRACT → RETURN COMPARISON

# LEVEL 3 — COORDINATION ROUND

USE WHEN:
- multiple independent scientific objects are already ready for routing,
  freezing, adjudication packaging, repair packaging, or next-pressure
  materialization;
- the goal is to reduce human coordination load without merging scientific
  contexts.

FORM:
MULTIPLE INDEPENDENT FROZEN / READY OBJECTS
+
ONE COORDINATION MANIFEST
+
MULTIPLE ADDRESSED TASKS
+
ONE BUNDLED RETURN TO INTEGRATION

REQUIREMENTS:
- every task retains its own address and context boundary;
- batching must not create prohibited information access;
- one task may not rely on another task's unseen output unless explicitly
  sequenced by the manifest;
- scientific units remain individually identifiable and auditable.

CANONICAL HUMAN ACTION:
RUN TASK LIST → PRESERVE ADDRESSES → COLLECT OUTPUTS → RETURN ONE BUNDLE

# LEVEL 4 — HORIZON REVIEW ROUND

USE WHEN:
- enough qualified state has changed to reconsider plan relevance;
- multiple lanes / axes must be integrated;
- local work may need continuation, branching, compression, repair, or
  reprioritization.

FORM:
TARGET / PURPOSE
+
PRIMARY AXES
+
CURRENT QUALIFIED FRAMES
+
RECENT CONSEQUENTIAL FRAMES
+
ACTIVE HORIZON
→
RELATIONAL-HORIZON REVIEW
→
UPDATED PRESSURE FAMILIES / PRIORITIES

REQUIREMENTS:
- horizon review uses qualified state, not unfrozen speculation;
- projected frames remain projections rather than future truth;
- reprioritization does not create execution authority;
- the review may modify plan topology only at candidate standing until
  separately qualified.

CANONICAL HUMAN ACTION:
SUPPLY QUALIFIED BUNDLE → REVIEW HORIZON → FREEZE UPDATED PLAN CANDIDATE → MATERIALIZE NEXT ROUND

# CROSS-LEVEL LAW

BATCHING MUST NOT CREATE INFORMATION ACCESS
THAT THE TEST CONTRACT PROHIBITS.

# CURRENT CLAIM CEILING

These four levels are sufficiently supported by the current workflow to be
recorded as candidate-canonical coordination modes.

This does NOT establish:
- completeness of the level set;
- autonomous orchestration;
- automatic level selection;
- authority to route or execute;
- generic scientific validity outside the tested workflow.

Additional levels may be appended later if operational pressure reveals
new coordination structures.
