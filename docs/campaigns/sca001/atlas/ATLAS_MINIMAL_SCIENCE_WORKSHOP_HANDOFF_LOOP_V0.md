# ==================================================
# PURPOSE
# ==================================================

Record the smallest workflow pattern that has now run repeatedly and
stably enough to pressure later as an operational object.

This artifact does NOT declare a final orchestration architecture.

It records a bounded observed loop that has reduced human coordination
load across Cells 002C through 003A.

# ==================================================
# OBSERVED LOOP
# ==================================================

SCIENCE / INTEGRATION ROLE:

1. identifies the next bounded scientific pressure;
2. materializes one complete ready-to-send packet;
3. embeds or addresses the exact source and contract;
4. freezes returned output before pressure variants are materialized;
5. records adjudication results;
6. advances only to the next lawful pressure.

WORKSHOP / EXTRACTION ROLE:

1. receives one addressed packet;
2. reads only the packet-bounded source and contract;
3. performs one bounded reconstruction / transformation task;
4. returns one structured result object;
5. does not admit, mutate topology, authorize, execute, or self-promote.

EVALUATION ROLE:

1. receives frozen evidence;
2. checks leakage, support posture, claim ceiling, provenance, and
   experimental administration;
3. returns one bounded adjudication;
4. does not repair the source or rewrite the frozen outputs.

HUMAN OPERATOR:

1. routes one package to one destination;
2. returns one result object;
3. remains experiment governor rather than protocol glue.

# ==================================================
# MINIMAL HANDOFF LAW
# ==================================================

ONE PACKAGE
+
ONE DESTINATION
+
ONE ACTION
+
ONE RETURN OBJECT

or:

SEND THIS
→ TO HERE
→ DO THIS
→ BRING BACK THAT

# ==================================================
# OBSERVED EFFECT
# ==================================================

The workflow has repeatedly supported a short cycle:

SOURCE / STATE
→ PACKET
→ REMOTE EXECUTION
→ FROZEN RESULT
→ ADJUDICATION
→ NEXT LAWFUL PRESSURE

without requiring the human operator to reconstruct scientific context,
assemble multi-part instructions, or manually merge competing artifacts
each turn.

Observed examples in this campaign include:

- Cell 002C:
  multi-fact relational reconstruction;
- Cell 002D:
  bounded relational-extent reconstruction with neutral variant repair;
- Cell 002E / 002F:
  geometry and role-invariance pressure;
- Cell 003A:
  history-conditioned relation recovery after a state-changing event.
