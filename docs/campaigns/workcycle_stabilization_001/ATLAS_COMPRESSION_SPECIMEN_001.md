## SEVEN-SURFACE CONSERVATION ENVELOPE

### IDENTITY / ADDRESS

Must preserve exact source-file challenge handles and round/task identifiers.

### MECHANICAL

Original files remain unchanged and cold-retained.
Candidate is additive only.

### SYMBOLIC / SEMANTIC

Must preserve each task's operative purpose and explicit prohibitions.

### RELATIONAL / TOPOLOGICAL

Must preserve:
- A/B parallel independence;
- B cannot inspect A current-round output;
- round-order progression;
- packet→task correspondence.

### CONSEQUENCE / ENVIRONMENTAL

Candidate may reduce hot-context burden only.
It must not activate work, authorize invocation, or alter historical result.

### PROVENANCE

Every compressed statement must be challengeable back to one of the three exact
source files.

### INVARIANCE / META-CONSERVATION

A fresh seat given only the candidate + exact source handles must reconstruct the
same bounded coordination posture without strengthening it.
