## Proposed WORKFLOW.md

```markdown
# Workflow

DME_Lab advances by applying bounded pressure to unresolved questions,
preserving evidence, adjudicating only what the basis supports, and conserving
structure only when it prevents consequential collapse or repeated epistemic
work.

This file answers: **how does the Lab move?**

It defines current research/development governance. It is not a universal
scientific ontology.

## Core movement

A common movement is:

```text
pressure
→ observe / retrieve evidence
→ compare / transform / reconstruct
→ evaluate
→ adjudicate or dwell
→ preserve evidence + residue
→ update current standing / navigation where warranted
```

The order is not mandatory. Retained evidence may be reevaluated without fresh
observation. External change may supply new evidence without DME execution.

## Evidence before closure

Keep distinct:

- proposed;
- executed / implemented;
- directly observed;
- derived / reconstructed;
- interpreted;
- adjudicated;
- authorized;
- unresolved / missing.

Do not repair missing evidence with interpretation.

Direct evidence may contradict current projections, but evidence does not
silently adjudicate itself.

## Standing transition

```text
EVIDENCE
→ EVALUATION
→ ADJUDICATION
→ CURRENT STANDING
→ DERIVED PROJECTION
```

This is a governance relation, not a claim that every scientific specimen
contains each stage.

When new evidence conflicts with prior standing:

- retain the new evidence and its basis;
- retain the prior adjudication and its basis as lineage;
- do not rewrite historical evidence to make the present look coherent;
- adjudicate the current relation when warranted;
- update current-state/navigation projections only after standing changes.

```text
supersession != historical invalidation
compression != forgetting
```

## Conservation and compression

Conserve a distinction, constraint, method, or root claim only when doing so:

- prevents demonstrated drift or unsupported collapse;
- preserves a consequential authority/evidence boundary;
- supports reconstruction;
- reduces repeated epistemically meaningful work.

Otherwise leave the system lighter.

Candidate compression success criterion:

```text
smaller live governing surface
+
same recoverable consequential distinctions
+
same or clearer authority routing
```

Compression fails if it hides contradiction, loses basis/provenance, erases
historical standing, or increases reconstruction debt enough that correct
action becomes harder.

## Navigation update

After adjudication:

- record the bounded resolution;

- link authoritative evidence;
- update current-state and navigation projections that are now stale;
- expose changed reachability;
- do not automatically authorize new execution.
