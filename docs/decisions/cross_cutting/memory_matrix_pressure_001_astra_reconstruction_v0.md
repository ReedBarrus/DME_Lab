## Fail conditions

- path/version/basis detachment;
- interpretation → standing promotion;
- historical state → present state promotion;
- proposal → architecture/schema promotion;
- unresolved conflict → apparent resolution;
- dependency loss;
- false currentness;
- loss of a required nonclaim;
- reliance on prior conversation to restore meaning.
