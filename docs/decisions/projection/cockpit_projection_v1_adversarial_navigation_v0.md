against the exact-current generated projection and all seven existing observer

- real projection defect;

## Concrete failures and minimum repairs

### F1 / R1 — ambiguous active identity

**Failure:** an explicit active pressure ID matching two node occurrences
marked both occurrences active.

**Repair:** occurrence-level `isActive` is now permitted only when the active
ID resolves to exactly one normalized pressure occurrence. Matching duplicates
remain inactive and expose `active occurrence ambiguous` beside their existing
duplicate-identity marker. The current-navigation strip still shows the exact
active pressure ID.

**LOCAL SUFFICIENCY:** prevents the two unsupported activity claims while
retaining the declared active ID and visible ambiguity.

**COMPOSITIONAL COMPATIBILITY:** preserves `pressure ID != occurrence
identity`, `selection != activity`, exact navigation state, duplicate
diagnostics, and all unique-ID activity behavior. It adds no activity source,
scientific standing, or relation.

**Audit standing:** `LOCALLY + COMPOSITIONALLY EARNED` workflow outcome.

### F2 / R2 — duplicate evidence-ID winner selection

**Failure:** an owner naming a duplicated evidence ID displayed the last
matching reference and model traversal could select either collision.

**Repair:** owner evidence rendering now distinguishes zero, one, and multiple
matching normalized evidence occurrences. Multiple matches render the exact
ID, occurrence count, and an explicit ambiguous/no-target-selected boundary.
No owner traversal control is emitted. `followEvidence` independently refuses
any evidence ID that does not resolve to exactly one occurrence. SOURCE still
lists and individually inspects both occurrences with their exact origins.

**LOCAL SUFFICIENCY:** removes last-write-wins evidence display and refuses an
ambiguous traversal coordinate.

**COMPOSITIONAL COMPATIBILITY:** preserves all unique evidence navigation,
exact resolution statuses, origin/provenance, independently addressable SOURCE
occurrences, and the no-proof boundary. It creates no reverse evidence-to-owner
relation and introduces no adapter identity rule.

**Audit standing:** `LOCALLY + COMPOSITIONALLY EARNED` workflow outcome.

No other implementation change survived the fix budget. A router, model
expansion, adapter allowlist expansion, new view, new ontology, or geometry
system would be `OVERBUILT` for the observed pressure.
