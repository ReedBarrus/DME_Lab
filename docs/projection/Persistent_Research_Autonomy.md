# Persistent Research Autonomy

> Non-authoritative projection.
>
> This document preserves an upstream question about persistent research,
> auxiliary processing, and long-range agent continuity.
>
> It does not authorize implementation of an orchestrator, controller,
> scheduler, planner, dependency engine, persistent agent, or autonomous
> research loop.
>
> Any structure described here must be independently earned through
> executable pressure before entering the operational system.

## Motivating Question

As DME becomes capable of preserving richer historical and observational
state, can that state support competent continuation of complex work across
replaceable or interrupted reasoning processes?

The projected target is not continuous model consciousness.

It is:

    investigator episode
    → durable qualified state
    → interruption / replacement
    → reconstruction
    → changed-world check
    → justified continuation

The core question is:

> Can a fresh competent worker recover enough epistemic footing to continue
> an investigation correctly without silently inheriting stale assumptions,
> duplicating consequential actions, or reconstructing the entire project
> from conversation?

## Why Preserve This Question

Current DME pressure has already exposed boundaries relevant to future
autonomy, including differences between:

    durable history
    and reconstructed representation

    current derived history
    and current external configuration

    caller outcome
    and durable world state

    recoverable evidence
    and publicly resolvable association

These results do not establish an autonomy architecture.

They make persistent continuation an increasingly legitimate future pressure.

## Projected Functional Roles

One possible decomposition is:

    human
    → objective, authority, consequence boundary

    investigator
    → hypothesis, experiment design, interpretation, revision

    bounded auxiliary workers
    → computation, execution, comparison, measurement

    DME
    → provenance-preserving evidence and reconstructable state

    controller / execution host
    → interruption, scheduling, budgets, resumption

This decomposition is explanatory only.

No component boundary is currently required by DME.

## Persistent Working State Candidate

A future investigation may benefit from durable external state describing:

    objective
    acceptance criteria
    authorization boundary

    competing interpretations

    evidence and counterevidence

    experiment attempts and outcomes

    unresolved questions

    dependencies between claims and observations

    potentially stale assumptions

    next currently justified pressure

    continuation brief linked to evidence

This would preserve external research state.

It would not serialize model weights, hidden reasoning state, or a persistent
subjective agent.

## Important Future Failure Modes

A long-running autonomous process must not silently assume:

    prior action acknowledged
    → action actually completed

    historical result recovered
    → external world still matches it

    result reference exists
    → supporting history has been resolved

    worker remembers intent
    → intent remains authorized

    task remains open
    → retry is safe

Lost acknowledgement is especially important:

    action attempted
    → external effect may occur
    → acknowledgement lost
    → worker interrupted
    → replacement worker resumes

A replacement worker must determine what actually happened before retrying.

## Candidate Future Pressure

If this question becomes operationally necessary, a minimal pressure could
compare continuation under:

    ordinary files / conversation

    structured checkpoint

    DME-mediated reconstruction

using the same bounded research task.

Interrupt each condition at comparable points.

Before resumption:

    change one external fact
    lose one acknowledgement
    invalidate one prior assumption

Then measure:

    stale assumptions reused
    duplicate actions
    unnecessary repeated work
    incorrect continuation
    human intervention
    recovery latency
    evidence-navigation failures

The structured-checkpoint baseline is required.

DME must demonstrate value beyond a carefully maintained state file.

## Dependency-Aware Invalidation

A projected later capability is:

    source changes
    → dependent claim becomes questionable
    → downstream projections become affected
    → reconsideration becomes available

This is currently only a projected behavior.

Do not implement a generalized dependency graph from this document.

A first legitimate implementation would require an observed case where one
changed source must invalidate one previously justified dependent conclusion.

## Relation to Attention and Consequence

Persistent autonomy may eventually intersect with attention allocation:

    unresolved consequential state
    → candidate pressure
    → bounded investigator
    → observation / action
    → changed reconstruction
    → changed reachable next pressure

This is not an attention architecture.

It preserves the possibility that future agent allocation may be grounded in
the same consequence and provenance structures being developed elsewhere.

## Current Standing

This question is shelved.

DME_Lab currently has one active experimental frontier at a time unless a
separate need independently justifies parallel work.

No autonomous controller, scheduler, persistent worker, auxiliary-processing
runtime, dependency invalidator, or agent ecology is authorized by this
projection.

## Reopening Conditions

Reopen this projection only when concrete pressure requires at least one of:

- competent continuation after real interruption;
- replacement of one investigator by another;
- ambiguity about whether a consequential action completed;
- stale external state invalidating prior research state;
- enough accumulated work that reconstruction cost itself becomes a measured
  problem;
- a real need to allocate bounded auxiliary work across multiple workers.

Until then:

    preserve the question
    continue the active pressure
