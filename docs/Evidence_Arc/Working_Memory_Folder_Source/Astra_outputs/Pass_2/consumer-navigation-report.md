# Consumer navigation pressure — bounded trial

The consumer discovered and followed a legitimate public evidence reference,
but did not establish that the returned history belonged to the supplied
specimen. It stopped with historical Git acquisition success unresolved.
No overclaim was found in the recorded answer by the investigator's audit.

The fresh consumer context inherited a general DME memory summary. Complete
unfamiliarity with DME implementation was therefore not fully established.
This is a constrained-context trial with an explicit limitation, not a
conclusive answer for a completely unfamiliar consumer.

## 1. Question and warrant

Can a consumer unfamiliar with DME_Lab implementation, using only the complete
`current_result()` surface and declared public navigation affordances, locate
enough historical evidence to determine whether the recorded Git acquisition
succeeded without making a stronger claim than the evidence warrants?

The supplied warrant authorized exploratory consumer-navigation pressure,
documented evidence requests, and explanation of warrant at each step. It
forbade source inspection, registry lookup, arbitrary repository searches,
prior Astra context, current external-state claims, generalized conclusions,
and production modification. The investigator prepared and audited evidence;
the separate consumer operated on the restricted packet.

## 8. Stopping condition

The consumer selected condition 4: **the evidence basis proves insufficient**.
It stopped after one legitimate request and response. It did not exhaust other
documentation references or inspect acquisition payloads from the unassociated
ledger. This is a bounded stopping decision, not proof that every possible
public navigation path would fail.

## 9. Underlying audit

The withheld specimen evidence contains three historical Git command failures;
HEAD, branch, and working-tree status are null. Exact saved ledger bytes pass
their saved SHA-256 and per-record digest checks. The saved reconstructed Git
payload equals the original raw Git observation.

The result was therefore recoverable for the investigator with the specimen's
actual historical evidence. The consumer did not receive that evidence because
its chosen public route did not establish an association to it. Unresolved was
an appropriately bounded answer on the reached evidence, even though the
investigator could determine the recorded outcome.

The investigator separately verified the public ledger's record count and
record-type mapping. Record-count difference alone would not exclude a later
extension of a history. The mismatched record roles, plus absence of a documented
association to S, defeat the attempted identification of the specific record.
No general history-identity theorem is claimed.

## 10. Concrete result and candidate distinction

This consumer could discover a cited evidence source. It did not reach enough
specimen-associated evidence to answer the acquisition question, and it did not
substitute an unrelated record with a matching identifier.

The local issue exposed is the association between a visible record reference
and the intended history through the supplied public navigation basis. A
reference's presence and the discoverability of that association were separate
in this attempt. This is a candidate scoped observation, not a registry entry
or an adopted repository conclusion.

## 12. Verification

Checks validate the unchanged specimen body, packet/document hashes, complete
delivery hash, saved specimen ledger hash, per-record integrity, reconstructed
payload equality, and public record-role mismatch. They validate evidence
handling, not the semantic correctness or independence of the consumer.

No implementation tests or hardware experiments were run: production was not
changed or executed. One consumer run, one request, one response, one stopping
decision. The broker/investigator audit is not independent adjudication.

## 13. Limits

This does not establish that a fully unfamiliar consumer would behave the same,
that all public routes fail, that source evidence was lost, that a new navigation
API is necessary, or that current external state is known. It does not establish
general navigation/agent capability or a production defect. The documentation
selection, inherited general memory, instruction-based isolation, and reuse of
a historical specimen remain explicit limits.

## 14. Smallest missing conditions

A strict unfamiliar-consumer repetition needs a context without inherited DME
memory. Resolving the task through the attempted navigation route also needs a
publicly discoverable association from S to its intended historical evidence.
The present run does not choose an implementation for that association.

No follow-up experiment or production change was executed after the stop.
